[GitHub로 APK 뽑기]
1. 이 ZIP 파일의 압축을 풉니다.
2. GitHub 새 저장소에서 'uploading an existing file'을 눌러 압축 푼 폴더 안의 모든 파일(.github 포함)을 업로드하고 Commit 합니다.
3. 저장소 상단 [Actions] 탭에서 빌드가 끝나면 하단 Artifacts에서 APK를 다운로드합니다.
